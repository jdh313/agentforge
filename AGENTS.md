# agentforge — Repo Instructions

This repository keeps a single set of agent instructions, and they live in
[`CLAUDE.md`](CLAUDE.md). Read that file.

The guidance there is harness-neutral despite the filename: terminology,
architecture, the render contract, common commands, and the conventions for
adding a target or an artifact all apply regardless of which agent or runtime
you are working from. Nothing in it is specific to one vendor's tooling.

This file used to carry a second, hand-maintained copy of that content. The
copy drifted — it described targets that do not exist, pointed at source files
under the wrong names, and claimed the project had no GitHub remote. One file
owning the instructions is the fix.
